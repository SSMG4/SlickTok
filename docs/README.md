# SlickTok docs

Start here. Pick the doc that matches what you're trying to do.

| I want to... | Read |
|---|---|
| Use the site, understand rate limits and supported links | [USAGE.md](USAGE.md) |
| Understand how it works internally, or its known limitations | [ARCHITECTURE.md](ARCHITECTURE.md) |
| Self-host my own instance | [DEPLOY.md](DEPLOY.md) |
| Contribute code, add a language, set up a local dev copy | [CONTRIBUTING.md](CONTRIBUTING.md) |
| Report a security vulnerability | [SECURITY.md](SECURITY.md) |
| Know what data SlickTok processes about visitors | [PRIVACY.md](PRIVACY.md) |
| Know the terms of service and acceptable use | [TERMS.md](TERMS.md) |
| Know community expectations | [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

If you're not sure, [USAGE.md](USAGE.md) is the friendliest starting
point, and [ARCHITECTURE.md](ARCHITECTURE.md) is the one to read
before changing any code.
